# fantastic-editor 0.2.0-rc.3

发布日期：2026-08-29
平台：Windows x64
状态：本机发布候选，未进行 Authenticode 签名

## 本版变化

- 完成可访问性与错误恢复两轮：状态播报、键盘分栏、解析重试、标签循环切换/关闭和主题预览模态焦点闭环。
- 增加标签拖动排序及 Alt+Shift+左右键移动，恢复快照保留顺序。
- 增加最近文件入口；Renderer 只获得不透明 recentId、文件名和时间，不获得绝对路径。
- 增加当前快照的解析、资源解析耗时与大文档分级提示。
- 增加所见即所得旧 SourceRange 投影的结构校验，阻止连续编辑时猜测性修改相邻公式、代码或 Mermaid。
