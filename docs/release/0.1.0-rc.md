# fantastic-editor 0.1.0 发布候选说明

> 状态：Windows x64 发布候选版，尚未完成代码签名。

本机已完成安装版“安装 → 启动 → 卸载”和最终单文件便携版启动冒烟；当前版本可用于 P0 候选测试，但在代码签名与第二台 Windows 验收完成前不标记为正式发行版。

## 交付文件

- `fantastic-editor-0.1.0-setup.exe`：NSIS 用户级安装包，可选择安装目录并创建桌面、开始菜单快捷方式。
- `fantastic-editor-0.1.0-portable.exe`：单文件便携版，不创建安装项、快捷方式或卸载项。
- `fantastic-editor-0.1.0-release-manifest.json`：两种 EXE 的字节数、SHA-256、SHA-512、版本和签名状态。

## 核心能力

- 新建、打开、拖入、编辑、保存和另存为本地 Markdown。
- 源代码与所见即所得双编辑模式，共享 canonical Markdown 与撤销历史。
- 本地图片拖入/按钮插入，KaTeX 公式、Mermaid、表格、列表和代码预览。
- PDF、DOCX、单文件离线 HTML 输出。
- 微信公众号方案 B：复制正文，按短 FE 标记逐项替换图片、公式和 Mermaid。

## 安装版与便携版数据边界

- 两种版本都使用 Electron 的用户数据目录保存界面偏好、恢复快照和未命名会话临时数据，不把这些数据写到 Markdown 正文。
- 便携版的“便携”只表示无需安装；当前版本不承诺把配置和恢复数据放在 EXE 同目录，也不承诺 U 盘跨机器携带应用状态。
- 卸载程序不得删除用户自行创建的 Markdown、图片或导出文件。清理应用偏好和恢复快照应由后续显式功能处理。

## 已知限制

- 构建尚未使用代码签名证书，Windows SmartScreen 可能显示“未知发布者”。
- 微信公众号图片、公式和 Mermaid 仍需用户按替换助手逐项粘贴；应用不自动发布或群发。
- 微信公众号“一键排版”可能破坏列表和代码样式，粘贴 fantastic-editor 正文后不建议再次套版。
- 公众号验收记录来自用户人工确认，不代表应用读取或自动验证平台最终草稿。
- P1 公众号多主题和 P2 封面对生成尚未实现。

## 发布前验证

1. `npm test -- --run`
2. `npm run typecheck`
3. `npm run build`
4. `npm run dist:rc`
5. 在参考 Windows 上验证安装、启动、升级覆盖、卸载和便携版启动。
6. 使用固定样例验证 Markdown 保存、图片、公式、Mermaid、PDF、DOCX、离线 HTML和公众号剪贴板。
