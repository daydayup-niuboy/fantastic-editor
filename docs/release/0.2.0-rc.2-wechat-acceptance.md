## 每套主题的完成条件

1. 使用 `release/fantastic-editor-0.2.0-rc.2-portable.exe` 打开 `fixtures/wechat-acceptance/standard.md`。
2. 在导出菜单选择目标主题并复制公众号正文。
3. 在真实公众号编辑器粘贴正文，按编号逐项替换普通图片、行内公式、块级公式和 Mermaid，确认所有 FE 占位文字消失。
4. 保存草稿，关闭并重新打开，确认标题层级、引用、表格、列表、代码、图片顺序和主题样式仍存在。
5. 完成公众号移动端预览，检查 320px 级窄屏下的正文、表格、公式、流程图和代码可读性。
6. 回到 fantastic-editor 勾选对应人工确认项并保存验收记录；记录中的应用版本和主题 ID 必须与本行一致。

## 操作边界

- 不需要发布或群发文章，保存为测试草稿即可。
- 内置浏览器当前因站点安全策略不能由自动化读取或操作微信公众号编辑页，平台侧结果必须由用户人工确认。
- 旧版本记录保留为回归基线，不复制为 `rc.2` 结果；任何主题或公众号投影代码变化后，相应主题需要重新验收。
