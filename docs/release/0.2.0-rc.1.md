# fantastic-editor 0.2.0-rc.1 便携候选说明

> 状态：P1 Windows x64 单文件便携候选版；未签名，不是正式公开发行版。

## 本版重点

- 公众号正文新增“微信原生增强、极简墨白、深蓝科技”三套原创主题，最终输出与本地预览复用同一受控主题定义和行内样式编译器。
- 导出菜单新增主题与手机预览；320px、375px、414px 三档探针自动并行检查横向溢出、局部滚动、小字号、文字对比度、标题间距、表格和代码宽度。
- 公众号普通图片、行内/块级公式和 Mermaid 继续使用方案 B 编号替换助手；主题切换不改变替换项、资源集合、省略集合或任务终态。
- 保留 P0 已完成的本地 Markdown 打开/新建/保存、源代码与所见即所得编辑、图片导入、同步滚动、PDF、DOCX、离线 HTML、公众号复制和恢复快照能力。

## 质量基线

- 自动测试基线：35 个测试文件、195 项测试。
- 必须通过严格 TypeScript 检查、生产构建和完整 Electron UI 冒烟；UI 冒烟包含主题预览打开及三档审计完成断言。
- 便携 EXE 生成后必须校验 PE MZ 头、产品版本、文件大小、SHA-256 和签名状态，并使用隔离 userData 启动一次。

## 已知边界

- 便携版表示无需安装，不承诺把设置和恢复数据保存在 EXE 同目录。
- 当前没有 Authenticode 证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 本地主题审计不代表微信公众号客户端兼容性已经自动验证，不会自动勾选 `mobilePreviewed`。
- 三套主题仍需在真实公众号后台分别完成粘贴、图片替换、保存、关闭重开和手机预览；这项人工验收不阻止生成供测试的候选 EXE，但阻止把它标记为正式版。
