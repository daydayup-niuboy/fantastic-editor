# fantastic-editor 0.2.0-rc.2 Windows 候选说明

> 状态：Windows x64 本机发布加固已完成；产物未签名，仍保持 RC 标识。

## 本版重点

- 修复公众号正文安全审计误判：HTML 生成层与主进程剪贴板层共用标签/属性级审计，正文中合法说明 `file:`、`data:`、`app:` 或 localhost 不再被当作活跃资源地址。
- 真实危险标签、事件属性、class/id 和标签属性或内联样式中的本地、临时、内嵌资源地址仍会阻止写入剪贴板。
- 公众号剪贴板写入或读回失败使用 `OUTPUT_CLIPBOARD_WRITE_FAILED`，不再误报为文件写入失败。
- 保留三套公众号主题、手机宽度审计、方案 B 图片/公式/Mermaid 替换、本地 Markdown、所见即所得、PDF、DOCX 和离线 HTML 能力。
